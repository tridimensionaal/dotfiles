# GTK

The GTK package links settings for GTK 3 and GTK 4:

- `~/.config/gtk-3.0/settings.ini`
- `~/.config/gtk-4.0/settings.ini`

## Settings

- Theme: `Adwaita`
- Icon theme: `Adwaita`
- Font: `Hack Nerd Font 11`
- Dark preference: enabled

This is a best-effort preference for GTK applications. Some applications may ignore it or use their own theme settings.

The GUI profile installs this package together with `alacritty`, `sway`, and `waybar`.
